# MyBike Landing Page

A modern, responsive landing page for MyBike, built with HTML, SCSS, and JavaScript.

[**Live Demo**](https://dimon2202.github.io/layout_landing-page_my-bike/) · [**GitHub Repository**](https://github.com/dimon2202/layout_landing-page_my-bike)

## Features

- Responsive design for mobile, tablet, and desktop.
- Clean and maintainable SCSS styles.
- Interactive UI elements.

## Tech Stack

- **HTML5** — Semantic markup.
- **SCSS/SASS** — Styling.
- **JavaScript** — Interactivity.
- **Parcel** — Development and build tool.
